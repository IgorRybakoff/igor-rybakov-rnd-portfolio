# Igor Rybakov — Independent R&D Portfolio

Independent research and engineering work in AI systems, knowledge architecture, agentic evaluation, system reliability, and human-centered AI safety.

> These projects are research directions, architecture concepts, and evolving prototypes. They are not presented as finished commercial products.

## Focus areas

- reliable interaction between language models and external knowledge;
- multi-model verification and uncertainty handling;
- stability and fault-tolerance of agentic systems;
- mechanistic experiments on neural-network generalization;
- preservation of human agency when working with AI.

## Core principle

**LLM never creates metrics; LLM only interprets measured evidence.**

The portfolio separates deterministic computation and verification from language-model interpretation wherever possible.

## Publication policy

This repository intentionally excludes API keys, private datasets, patent drafts, security-sensitive materials, defense-related systems, and non-public implementation details.
